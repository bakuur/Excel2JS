Help / How it works

Paste any JSON. The tool scans for arrays of objects. Choose which array to turn into a table. Headers are the union of all object keys. Nested objects are optionally flattened using dot notation (e.g. address.city). Nested arrays or objects that can't be flattened are stringified.

If you enable Explode arrays, arrays of primitives directly under each row will generate multiple output rows (Cartesian style only for first such array encountered).

Privacy: All parsing and table generation run locally in your browser. No JSON or data is uploaded or transmitted anywhere.
